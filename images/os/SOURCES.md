# Operating system logos

- `apple.svg`, `linux.svg`, `docker.svg`, `ubuntu.svg`, `centos.svg`: vector icon paths from [Simple Icons](https://github.com/simple-icons/simple-icons) (CC0), with local fill colors added for the download page.
- `baidu.svg`: Baidu paw icon vector path from [Simple Icons](https://github.com/simple-icons/simple-icons) (CC0), with a local blue fill for the Hou China mirror button.
- `windows.svg`: simple four-pane Windows-style vector mark created for the download page.

All six SVGs are stored locally for rendering without third-party image requests. OS names remain in the download page image alternative text.
