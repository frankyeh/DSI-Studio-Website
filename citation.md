# Citations

## General citation for DSI Studio and Fiber Data Hub

When citing DSI Studio, cite the 2025 *Nature Methods* paper and report the **exact DSI Studio release used for the analysis**. The version family (Sun, Hou, Chen, etc.) may be included as additional information, but it should not replace the exact release date.

**Recommended citation**

```text
Yeh FC. DSI Studio: an integrated tractography platform and fiber data hub for accelerating brain research. Nature Methods. 2025;22(8):1617-1619. doi:10.1038/s41592-025-02762-8.
```

[Nature Methods article](https://doi.org/10.1038/s41592-025-02762-8)

**Example methods statement**

> The analysis was conducted using DSI Studio (Yeh, 2025), version YYYY.MM.DD (Sun).

For reproducibility, keep a copy of the DSI Studio version used for each project and report relevant reconstruction/tracking parameters in the methods.

## Method-specific citations

Use the corresponding method paper when a study relies substantially on one of the following methods.

### Differential tractography and SRC quality control

Differential tractography maps pathway segments showing changes in diffusion measurements. The same paper introduced neighboring-DWI correlation as a diffusion-data quality-control measure used by DSI Studio.

```text
Yeh FC, Zaydan IM, Suski VR, Lacomis D, Richardson RM, Maroon JC, et al. Differential tractography as a track-based biomarker for neuronal injury. NeuroImage. 2019;202:116131. doi:10.1016/j.neuroimage.2019.116131.
```

[PubMed](https://pubmed.ncbi.nlm.nih.gov/31472253/)

### Correlational tractography / tractography methodology

```text
Yeh FC, Irimia A, Bastos DCA, Golby AJ. Tractography methods and findings in brain tumors and traumatic brain injury. NeuroImage. 2021;245:118651. doi:10.1016/j.neuroimage.2021.118651.
```

[PubMed](https://pubmed.ncbi.nlm.nih.gov/34673247/)

### Group connectometry

Connectometry tests statistical associations in local connectome measurements and uses permutation testing for inference.

```text
Yeh FC, Badre D, Verstynen T. Connectometry: A statistical approach harnessing the analytical potential of the local connectome. NeuroImage. 2016;125:162-171. doi:10.1016/j.neuroimage.2015.10.053.
```

[PubMed](https://pubmed.ncbi.nlm.nih.gov/26499808/)

### Tract-to-region connectome

```text
Yeh FC. Population-based tract-to-region connectome of the human brain and its hierarchical topology. Nature Communications. 2022;13:4933. doi:10.1038/s41467-022-32595-4.
```

[Nature Communications](https://www.nature.com/articles/s41467-022-32595-4)

### Shape analysis and augmented fiber tracking

The same study describes tractography shape metrics and the augmented fiber-tracking strategies used to improve the reproducibility of deterministic tracking.

```text
Yeh FC. Shape analysis of the human association pathways. NeuroImage. 2020;223:117329. doi:10.1016/j.neuroimage.2020.117329.
```

[PubMed](https://pubmed.ncbi.nlm.nih.gov/32882375/)
