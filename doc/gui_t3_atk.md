# AutoTrack and Tractometry

> **Before AutoTrack or tractometry:** [Import diffusion data](/doc/gui_t1.html) → [reconstruct a FIB file](/doc/gui_t2.html) → [check whole-brain tractography](/doc/gui_t3_whole_brain.html). You need an anatomically plausible <span class="gui-file-ext">.fz</span> and an appropriate tractography atlas; start on this page once those checks pass. For tract measurements, first map or load the named bundles.

AutoTrack maps named white-matter pathways using DSI Studio's tractography atlas. It is useful when the goal is to map a specific anatomical bundle consistently across subjects.

> **[Run conventional whole-brain tracking first](/doc/gui_t3_whole_brain.html).** AutoTrack should be used only after confirming that the diffusion data, b-table, reconstruction, and general tractography quality are anatomically reasonable.

Streamlines are computational trajectories generated by the tracking algorithm. Their count should not be interpreted as an axon count or a direct measure of biological connection strength.

*The video above may show an older interface. The steps below use current GUI labels.*

## Basic workflow

### 1. Open the FIB file

From the current main window, choose <span class="gui-menu-path"><span class="gui-menu-item">Tractography</span><span class="gui-menu-sep" aria-hidden="true">›</span><span class="gui-card"><span class="gui-card-num" aria-hidden="true">3</span><span class="gui-b">3 </span>Track</span><span class="gui-menu-sep" aria-hidden="true">›</span><span class="gui-action">FIB File (*.fz)</span></span> to open the fiber tracking window. For multiple subjects, use <span class="gui-menu-path"><span class="gui-menu-item">Tractography</span><span class="gui-menu-sep" aria-hidden="true">›</span><span class="gui-card"><span class="gui-card-num" aria-hidden="true">3</span><span class="gui-b">3 </span>Track</span><span class="gui-menu-sep" aria-hidden="true">›</span><span class="gui-action">▸ More…</span><span class="gui-menu-sep" aria-hidden="true">›</span><span class="gui-action">Automatic tracking</span></span> to open the separate batch AutoTrack interface.

### 2. Check whole-brain tractography

Restore the normal tracking settings and generate a representative whole-brain tractogram. Check major pathways and fiber orientations before continuing.

See [Whole-Brain Fiber Tracking](/doc/gui_t3_whole_brain.html) for the general tracking workflow.

### 3. Enable AutoTrack

Use <span class="gui-menu-path"><span class="gui-menu-item">Tracts</span><span class="gui-menu-sep" aria-hidden="true">›</span><span class="gui-menu-item">Autotrack...</span></span> and select the target tract or tract group.

DSI Studio uses the selected tractography atlas and the subject-to-template mapping to recognize streamlines belonging to the requested pathway. AutoTrack entries are hierarchical: choose the parent entry when the whole tract family is intended and a child entry only when a specific subdivision or branch is requested.

Standard named AutoTrack bundles already include atlas-defined anatomical constraints. Do not add extra ROI, ROA, End, Seed, NotEnd, Limiting, or Terminative regions by default. Add an extra region only when the study has a specific anatomical reason, such as isolating a minor branch.

### 4. Run Fiber Tracking

Click <span class="gui-action">Fiber Tracking</span> to generate the bundle. Inspect the result in multiple views and compare it with expected neuroanatomy.

If a pathway is incomplete or contains implausible branches, first determine whether the problem comes from acquisition/reconstruction quality before adjusting tracking parameters.

## Important AutoTrack parameters

| Parameter | Guidance |
|:--|:--|
| **Target tract** | Select the anatomical bundle to map. Use the current atlas entry; select the parent for the whole tract family and a child only for a requested subdivision. |
| **AutoTrack tolerance** | Controls how far candidate streamlines may deviate from the atlas definition. In the single-subject tracking window, the default is initialized from the loaded FIB data. The separate batch AutoTrack dialog starts at `22,26,30` mm and does not automatically update its tolerance on loading FIB data. Review it for species and image scale; increase it only when anatomical evidence supports a wider tolerance. |
| **Track/Voxel Ratio** | Controls the amount of tractography generated. The current default is derived from the FIB data rather than a universal fixed value. |
| **Min Length** | Removes short fragments. Set it according to the expected pathway and image scale. |
| **Topology-Informed Pruning (TIP)** | Use TIP on a sufficiently populated, visually coherent bundle. When a bundle reaches roughly 5,000–10,000 or more tracts before pruning, **3–4 iterations** are a practical starting point. TIP is not generic whole-brain cleanup. |
| **Check endings** | AutoTrack can use atlas-defined ending constraints. Keep the default unless the tract definition or study design requires otherwise. |

Parameter choices should be kept consistent across subjects in a comparative study.

## Troubleshooting AutoTrack

If AutoTrack repeatedly produces no result or poor anatomy, check the upstream data before tuning the tract-recognition settings.

1. Run [SRC quality control](/doc/gui_t1.html#step-t1a-quality-control).
2. Verify the image orientation and b-table orientation during [reconstruction](/doc/gui_t2.html).
3. Open the <span class="gui-file-ext">.fz</span> file and confirm that principal fiber directions are anatomically plausible.
4. Run [whole-brain tracking](/doc/gui_t3_whole_brain.html) and confirm that major pathways can be reconstructed.
5. Make sure the selected tractography atlas/template is appropriate for the dataset.

Small or difficult pathways may fail in some subjects when spatial resolution, angular sampling, b-value, SNR, or coverage is insufficient. Relaxing AutoTrack parameters cannot recover anatomical information that is absent from the acquisition.

If an unexpected problem persists, share the relevant SRC/FIB data through the **Data Upload** link and describe the issue on the [DSI Studio forum](https://groups.google.com/g/dsi-studio).

## Batch AutoTrack across subjects

For a cohort, open <span class="gui-menu-path"><span class="gui-menu-item">Tractography</span><span class="gui-menu-sep" aria-hidden="true">›</span><span class="gui-card"><span class="gui-card-num" aria-hidden="true">3</span><span class="gui-b">3 </span>Track</span><span class="gui-menu-sep" aria-hidden="true">›</span><span class="gui-action">▸ More…</span><span class="gui-menu-sep" aria-hidden="true">›</span><span class="gui-action">Automatic tracking</span></span> in the main window. This opens the separate batch AutoTrack interface, which accepts multiple FIB subjects and produces aggregated statistics.

1. Select the <span class="gui-file-ext">.fz</span> files and named tract groups to process.
2. Review the tractography atlas, tolerance, and track density for the anatomy and image scale.
3. Test a small subset and inspect the reconstructed pathways.
4. Change tolerance, density, or pruning only when anatomical evidence justifies it.
5. Apply the finalized settings consistently to the study.

**Important:** The batch interface initially sets **Tolerance** to `22,26,30` mm; loading a FIB does **not** automatically update it. **Track/Voxel Ratio** is initialized from the first FIB. Review tolerance carefully for pediatric, animal, and differently scaled acquisitions.

If several subjects fail or produce implausible tracts, review [SRC quality control](/doc/gui_t1.html#step-t1a-quality-control), b-table and volume orientation, representative [whole-brain tractography](/doc/gui_t3_whole_brain.html), atlas/template suitability, and acquisition SNR/resolution. Do not use relaxed constraints to conceal systematic upstream problems.

## Tractometry

After a tract has been mapped, DSI Studio can quantify its shape and diffusion measurements.

## Tract statistics

Use <span class="gui-menu-path"><span class="gui-menu-item">Tracts</span><span class="gui-menu-sep" aria-hidden="true">›</span><span class="gui-menu-item">Statistics</span></span> to obtain tract-level measurements. Depending on the loaded data, these can include:

- streamline/pathway length and span;
- tract volume and surface/shape measurements;
- QA and normalized QA;
- DTI measurements such as FA, MD, AD, and RD;
- other diffusion indices saved in the FIB file;
- values sampled from additional images inserted into the tracking window.

For interpretation of diffusion measurements, see [How to Interpret dMRI Metrics](/doc/how_to_interpret_dmri.html).

Additional NIfTI measurements such as structural MRI, quantitative MRI, PET, or other maps can be inserted with <span class="gui-menu-path"><span class="gui-menu-item">Slices</span><span class="gui-menu-sep" aria-hidden="true">›</span><span class="gui-menu-item">Insert Other Images</span></span> and sampled along the tract when they are correctly aligned.

## Tract profile

Use <span class="gui-menu-path"><span class="gui-menu-item">Tracts</span><span class="gui-menu-sep" aria-hidden="true">›</span><span class="gui-menu-item">Tract Profile</span></span> to examine how a measurement changes along a pathway rather than reducing the tract to one mean value.

Profiles can be parameterized by image axes or by fiber orientation. Keep the same profile definition and bandwidth when comparing subjects.

For region-to-region (R2R) or tract-to-region (T2R) connectivity analysis, see the separate [Connectome guide](/doc/gui_connectome.html).
