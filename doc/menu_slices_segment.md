# [Slices Segment] Menu

Use the **[Slices Segment]** menu in the Fiber Tracking window to segment the currently selected 3D image slice into anatomical tissues, subcortical nuclei, perivascular spaces, or pathological lesions using pre-packaged 3D U-Net deep-learning models, adding each predicted structure directly to the **Assign Regions** dock. Clicking **Segment...** in the **Assign Regions** dock toolbar opens this exact same menu. Model entries are populated dynamically at startup from DSI Studio's `unet/` catalog according to the active species template (`human`, `rhesus`, `marmoset`, `rat`, or `mouse`). Template-based skull stripping (**[Slices][Skull Strip...]**) and 3D mesh extraction (**[Slices][Add Isosurface]**) are located in the adjacent [Slices menu](/doc/menu_slices.html).

## How slice segmentation works

1. **Select a species template:** In the **Assign Regions** dock, choose the species template (`human`, `rhesus`, `marmoset`, `rat`, or `mouse`) matching the dataset. DSI Studio rebuilds **[Slices Segment]** with every packaged `.nz` model registered for that species (`19` models for `human`, `1` for `rhesus`, `3` for `marmoset`, `2` for `rat`, and `2` for `mouse`; templates without matching U-Net packages display an empty menu). Hovering the cursor over any model entry opens a pop-up description summarizing its target MRI contrast and output labels.
2. **Select and align the target slice:** Choose the image volume to segment in the slice selector dropdown at the top-left of the central 3D viewport toolbar (above the 3D view; for example, an inserted 3D T1w, T2w, or FLAIR volume loaded via **[Slices][Insert Other Images...]**). DSI Studio checks the active slice's display name (case-insensitive) against each model's modality requirement:
   - Models requiring T1-weighted input check for `t1` or `mpr` in the slice name and otherwise disable themselves with a `(need T1w)` prefix.
   - Models requiring T2-weighted input check for `t2` or `tse` in the slice name and otherwise disable themselves with a `(need T2w)` prefix.
   - Models requiring FLAIR input check for `flair` or `t2f` in the slice name and otherwise disable themselves with a `(need FLAIR)` prefix.
   - Contrast-flexible models remain enabled on every slice, including inserted structural MRI scans and built-in diffusion maps (`qa`, `iso`, `dwi`, `fa`).
3. **Automatic model caching and preprocessing:** Clicking an enabled entry waits for any background slice-to-diffusion registration on the active custom slice to complete, downloads the compressed `.nz` model package into DSI Studio's local application data `unet/` cache on first use, and loads the cached weights on later sessions. When a model package specifies brain-extraction preprocessing on a non-diffusion structural slice, DSI Studio projects the template brain mask into slice space, feathers the mask edge with two Gaussian smoothing passes, and masks a temporary copy of the volume for inference without altering the displayed slice.
4. **Generated regions in native slice space:** Synchronous 3D U-Net inference runs at the active slice's native voxel spacing (in mm) and appends each foreground label class to the **Assign Regions** table using that slice's exact grid dimensions, millimeter resolution, and slice-to-diffusion registration transform. Newly created regions default to **Type** `...` (passive visualization and measurement, leaving active fiber-tracking constraints unchanged until you switch **Type** to `ROI`, `ROA`, `Seed`, `End`, and so on) and receive anatomy-tuned colors and opacity—sheer translucency for outer head, skull, and dura; moderate translucency for white matter, cortex, CSF, ventricles, brainstem, vessels, and edema; and high-visibility opacity for deep nuclei, enhancing tumor, and necrosis.

## Practical recommendations and cautions

- **Prefer isotropic 3D structural scans over thick-slice 2D series:** Because 3D U-Net inference operates directly on the active slice volume, ~1 mm isotropic 3D structural MRI (such as MPRAGE, 3D T2w SPACE/CUBE, or 3D FLAIR) produces substantially cleaner anatomical and lesion boundaries than clinical 2D acquisitions with thick slices (for example `0.5 × 0.5 × 5 mm`) or lower-resolution diffusion maps (`2–2.5 mm`).
- **Verify slice-to-diffusion alignment before segmenting:** Generated regions inherit the active slice's registration transform into diffusion space. Inspect structural-to-diffusion alignment across sagittal, coronal, and axial views—and refine alignment with **[Slices][Adjust Slice Registration...]** if needed—before segmenting or evaluating tract-to-region relationships.
- **Keep contrast tags in structural filenames:** Modality-specific entries unlock based on `t1`/`mpr`, `t2`/`tse`, or `flair`/`t2f` in the slice's display name. Naming imported files clearly (such as `sub-01_T1w.nii.gz`, `sub-01_T2w.nii.gz`, or `sub-01_FLAIR.nii.gz`) ensures the matching models enable automatically. Because any T1-named slice also enables **U-Net Studio Human T1w-gd Tumor (1.3MB)**, double-check that the scan actually has gadolinium contrast before choosing that model.
- **Combining tumor compartments and checking empty classes:** Multi-label models create one row per model label class; if a compartment (such as `Necrosis` in a non-necrotic glioma) has zero predicted voxels, its row appears empty (`0` voxels). Use **[Regions][Statistics...]** to verify region volumes (`mm³`) and bounding-box dimensions, and duplicate/merge `Enhancing Tumor` with `Necrosis` via **[Regions]** and **[Region Edit]** when you need a unified `Tumor Core` region while keeping the original compartments intact.
- **Always review boundaries visually:** Automated 3D U-Net segmentation is intended for research and visual decision support and can misclassify postoperative cavities, hemorrhage, severe susceptibility distortion, or atypical anatomy. Inspect every generated region across all three orthogonal slice planes and clean up disconnected false-positive islands in **[Region Edit]** before quantitative reporting or tract filtering.
